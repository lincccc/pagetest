详细描述

该接口类提供了图像频域变换相关的算法，如快速离散傅里叶变换（FFT）， 以及频域图像的分析，如幅值、相位和相位相关。

使用这个接口，需要创建一个 LFreqTransform 对象。

变换总是输出全谱复数图像，频谱的布局由 DCTerm 控制。 复数图像包含 2 个通道，通道 0 为实部，通道 1 为虚部。

各属性用于配置正变换，不影响各方法的输出契约。

freqFilter->SetTemplate(freqImg->Width, freqImg->Height, LPVFreqDCCenter);
freqFilter->GenDirectionalBandpass(0.5, 1.0, 90, 2, filterImg, false);
freqFilter->Apply(freqImg, filterImg, filteredFreqImg);
// compute the inverse fast Fourier transform of the image
freqTrans->FFTInv(filteredFreqImg, cleanImg);

void FFT ( ILImage *  img,
ILImage *  freqImg 
)

计算图像的傅里叶变换，将图像转换到频域，使用快速傅里叶变换算法。 若输入为彩色图像则先转为灰度图像，并统一转为 32 位浮点后再进行变换。 变换前会根据 WindowFunction 对输入图像加窗，以减少频谱泄露。 如需还原图像，调用 FFTInv() 时使用相同的 DCTerm 。

参数
[in]img 输入的图像
[out]freqImg 返回傅里叶变换后的结果图，尺寸与输入图像相同

◆ PhaseCorrelation()

void PhaseCorrelation ( ILImage *  freqImg1,
ILImage *  freqImg2,
ILImage *  result 
)

计算两个频域图像的归一化互功率谱，用于相位相关计算。公式如下： \( \frac{conj(F_1) \cdot F_2}{|conj(F_1) \cdot F_2|} \) 。
结果仍为频域图像，若需定位峰值（即两个输入图像之间的位移），可再调用 FFTInv() 将其转回空间域。

参数
[in]freqImg1 第一个输入的频域图像
[in]freqImg2 第二个输入的频域图像
[out]result 返回归一化的互功率谱，尺寸与输入相同
