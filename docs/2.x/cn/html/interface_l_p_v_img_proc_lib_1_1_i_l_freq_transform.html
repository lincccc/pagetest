详细描述

该接口类提供了图像频域变换相关的算法，如快速离散傅里叶变换（FFT）。

使用这个接口，需要创建一个 LFreqTransform 对象。

自从
2.20.0

ILFreqTransformPtr freqTrans = LFreqTransform::Create();
// compute the fast Fourier transform of the image
imgfreq->FFT(img, freqImg);
// filter to select certain frequencies
ILFreqFilterPtr freqFilter = LFreqFilter::Create();
freqFilter->FilterType = LPVFreqFilterBandPassDirectional;
freqFilter->Apply(freqImg, freqFiltered);
// compute the inverse fast Fourier transform of the image
imgfreq->FFTInv(freqFiltered, cleanImg);

计算频域图像的幅值图，即频率的模： \( \sqrt{r^2 + i^2} \) .
若 doLn 设置为 True，则在结果上再计算自然对数： \( \ln{\sqrt{r^2 + i^2}} \) .

参数
[in]img 输入的频域图像
