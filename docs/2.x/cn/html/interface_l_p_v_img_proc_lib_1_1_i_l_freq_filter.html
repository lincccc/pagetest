详细描述

该接口类提供了图像频域滤波相关的算法。

使用这个接口，需要创建一个 LFreqFilter 对象。

滤波分为 3 个步骤：

  1. 通过 Width 、::Height 和 DCTerm 逐个描述滤波器所要作用的频谱，或通过 SetTemplate() 一次性设置。 该步骤必须在生成滤波器之前完成，所有生成的滤波器图像尺寸均为 Width [x] Height ；
  2. 通过 Gen...() 系列方法生成滤波器图像。滤波器图像可像普通图像一样保存、编辑， 也可通过图像运算与其他滤波器组合（例如，两个高斯滤波器的差即为高斯差分滤波器）；
  3. 通过 Apply() 或 ApplyGabor() 将滤波器图像应用到频域图像。

生成的滤波器图像并非都是同一类型的图像：

  • 大部分是单通道实数图像，每个像素为其频率的增益，包括高斯、理想、正弦、方向、均值和同态滤波器；
  • 导数滤波器是复数图像，包含实部和虚部，必须作为复数滤波器使用；
  • Gabor 滤波器为 2 通道图像，通道 0 为 Gabor 响应，通道 1 为 Hilbert 响应，它们是两个实数滤波器 而非一个复数的实部与虚部，因此需使用 ApplyGabor() 而非 Apply() 来应用它。

生成方法中的 frequency 和 bandwidth 为归一化频率，1 表示 Nyquist 频率， 对应的频谱像素半径约为 \( f \times width / 2 \) 。 各角度参数的单位均为度。

将滤波器图像应用到输入的频域图像，结果为频谱与滤波器的逐像素乘积。

滤波器图像可以是单通道实数图像，此时分别与频谱的实部、虚部相乘；也可以是 2 通道复数图像， 此时将频谱与一个复数相乘。滤波器图像的尺寸必须与频域图像完全一致。

参数
[in]freqImg 输入的频域图像
[in]filterImg输入的滤波器图像，为实数图像或与 freqImg 尺寸相同的复数图像
[out]result 返回滤波后的频域图像，尺寸与输入相同

void GenGabor ( double  angle,
double  frequency,
double  bandwidth,
double  orientation,
ILImage *  filterImg

生成 Gabor 滤波器图像，它是同时具有频率选择性和方向选择性的带通滤波器， 适合增强尺度相近且方向相近的纹理。

生成的图像为 2 通道图像，通道 0 为 Gabor 响应，通道 1 为对应的 Hilbert 响应， 因此需使用 ApplyGabor() 而非 Apply() 来应用它。

参数
[in]angle角向选择因子，取值范围为 1 ~ 500 ，数值越大，允许通过的方向范围越窄
[in]frequency归一化的中心频率，取值范围为 0 ~ 0.7
[in]bandwidth归一化的径向带宽因子，取值范围为 0.05 ~ 100 ，数值越大，允许通过的尺度范围越窄
[in]orientation滤波器的主方向，单位为度，取值范围为 0 ~ 180
[out]filterImg 返回 2 通道的滤波器图像，两个通道均为实数
