详细描述

该接口提供条码检测和质量评价的功能。

支持大多数流行的一维和二维码，具体列表请查看 LPVBarcodeType 。 质量评价符合 ISO-15416（一维码）和 ISO-15415（二维码）标准。

示例代码

C++
ILBarcodeDetectorPtr barcodeDetector = LBarcodeDetector::Create();
barcodeDetector->Type = LPVBarcodeType::LPVBarcodeAll1D; // detect all types of 1D barcode
barcodeDetector->VerifyQuality = VARIANT_TRUE; // do quality verification during detection
barcodeDetector->MaxCount = 3;
LPVErrorCode err = barcodeDetector->Detect(img, roi, &codeResults);
if (err != LPVErrorCode::LPVNoError) return;

◆ SymbolSize

int SymbolSize
getset

预期的符号尺寸，以符号每边的模块数表示。
默认设置为 0，表示不限制符号尺寸。
设置为非零值时要求符号是恰好该尺寸的方形码，并同时把 SymbolSizeMin 与 SymbolSizeMax 设置为该值。 仅当可接受的尺寸收敛为这一个方形码时，读取该属性才返回该值，否则返回 0。
注意该属性表示符号中模块的数量，不是单个模块的尺寸，后者见 ModuleSize 。

非零值必须是所检测码制（见 #Type）允许的符号尺寸，否则被拒绝。 各码制的实际生效范围如下：

码制实际生效范围（每边模块数）
Data Matrix（ECC 200）方形 10×10 … 144×144；矩形 8×18 … 16×48
Micro QR11×11、13×13、15×15、17×17
QR 码21×21 … 177×177（version 1~40，步长 4）
Aztec15×15 … 151×151（compact 15~27，full range 19~151）
PDF417行 3~90、数据列 1~30（非模块边长）
MaxiCode固定 30×33 六边形网格，无尺寸选项

矩形符号（如 \( 8 \times 18 \) ）无法用这一个数值表达，仅在该属性为 0 时才会被搜索。 如需按尺寸范围限制矩形码，请使用 SymbolSizeMin 与 SymbolSizeMax 。
