枚举类型说明

◆ LPVDCTermMode

enum LPVDCTermMode

该枚举表示频域图像中直流分量（零频分量）的位置。 枚举取值与频域算法引擎的取值对齐。

自从
2.24.0
枚举值
LPVFreqDCCenter 

直流分量位于频域图像的中心，便于观察频谱

LPVFreqDCEdge 

直流分量位于频域图像的左上角，即离散傅里叶变换的原始布局

◆ LPVEdgePreserveFilter

enum LPVEdgePreserveFilter

该枚举用于指定保变滤波使用的方法。 有助于纹理去除、以及分割之前的边缘提取。
自从 2.17.0

枚举值
LPVEPFFastGuided 

快速导向滤波，对导向滤波加速优化，且几乎没有视觉效果上的损失。
可通过参考图提供额外的边缘信息。在强纹理附近，可能产生边缘光晕。
该算子性能最佳，耗时与图像尺寸线性相关。但对于大块低对比度纹理的平滑效果不及其他方法。

LPVEPFWeightedLS 

一种基于加权二乘优化框架的保边滤波算子。
滤波结果可保留比较强的边缘，同时尽量平滑平坦区域，对于基础细节分解非常有效。通常无边缘光晕。
这种方法是我们提供的三种保边滤波算子中最慢的一种，且使用较多的内存。

LPVEPFL0Smooth 

该保边滤波算子以有效地将大多数梯度强制为 0 为优化目标。
它通常会生成类似卡通效果的、局部区域为统一数值的图像。通常无边缘光晕。
该算子的性能优于 LPVEPFWeightedLS，但比 LPVEPFFastGuided 慢。

◆ LPVWindowFunction

enum LPVWindowFunction

该枚举表示频域变换前对输入图像施加的窗函数。 窗函数可减少图像边界截断造成的频谱泄露。 枚举取值与频域算法引擎的取值对齐。

自从
2.24.0
枚举值
LPVWindowNone 

不使用窗函数

LPVWindowHamming 

汉明窗，两端数值为 \( 0.08 \) 的升余弦窗

LPVWindowHann 

汉宁窗，两端数值为 0 的升余弦窗

LPVWindowBlackman 

布莱克曼窗，相比汉明窗和汉宁窗具有更低的旁瓣，但主瓣更宽

LPVWindowFlattop 

平顶窗，幅度误差最小，但主瓣最宽

LPVWindowKaiser 

凯塞窗，其形状由 形状因子 控制
