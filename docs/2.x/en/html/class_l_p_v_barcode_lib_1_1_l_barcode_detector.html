void SetSymbolSizeRange (int minSize, int maxSize)
 Set the lower and upper bounds of the accepted symbol size range at once.
It is equivalent to setting SymbolSizeMin and SymbolSizeMax in one call, and is rejected atomically when either value is invalid, i.e. both bounds stay unchanged.
A value of 0 means no bound on that side. A non-zero value must be a symbol size allowed by the symbologies being detected, see the table in SymbolSize. LPVBarcodeSymbolShape SymbolShape [get, set]
 The expected symbol shape.
By default, it's LPVBarcodeSymbolShapeAny, accepting symbols of every shape.
LPVBarcodeSymbolShapeSquare restricts the detection to square symbols and LPVBarcodeSymbolShapeRectangle to rectangular ones, e.g. \( 8 \times 18 \) .
The exact SymbolSize must be 0 while the shape is LPVBarcodeSymbolShapeRectangle, a rectangular symbol cannot be described by a single module count; use SymbolSizeMin and SymbolSizeMax instead. Both bounds apply to every shape: a rectangular symbol is searched when its shorter side is at least SymbolSizeMin and its longer side is at most SymbolSizeMax, and a range that matches no rectangular size is rejected.
With LPVBarcodeSymbolShapeAny both square and rectangular symbols are searched; a symbol is accepted when every side of it is within the bounds. When both bounds are equal, only the symbol of exactly that size is searched. More...
