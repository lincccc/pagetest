Detailed Description

This interface provide functionalities of filters in frequency domain.

To use this interface, you should create a LFreqFilter object.

The filter is decoupled in 3 steps:

  1. describe the spectrum that the filter is used for with Width, Height and DCTerm, either one by one or at once with SetTemplate(). This step is required before generating a filter, the size of every generated filter image is Width [x] Height ;
  2. generate a filter image with one of the Gen...() methods, the filter image could be saved or edited like a normal image, and it could be combined with other filters by the image arithmetic operations (for example, the difference of 2 Gaussian filters produces a difference of Gaussian filter);
  3. apply the filter image to a frequency image with Apply() or ApplyGabor().

The generated filter images are not all the same kind of image:

  • most of them are a single channel real image which holds the gain of each frequency, including the Gaussian, ideal, sinusoidal, directional, mean and homomorphic filters;
  • the derivative filters are complex images, which have a real and an imaginary part, and they must be applied as a complex filter;
  • the Gabor filter has 2 channels, channel 0 is the Gabor response and channel 1 is the Hilbert response, they are 2 real valued filters rather than the real and imaginary parts of a complex number, so it's applied by ApplyGabor() instead of Apply().

frequency and bandwidth used by the generators are relative frequencies, 1 means the Nyquist frequency, the corresponding pixel radius of the spectrum is \( f \times width / 2 \) . The angle parameters are all in degree.

2.20.0

ILImage *  result

Applies the filter image to the input frequency image, the result is the pixel-wise product of the spectrum and the filter.

The filter image may be a single channel real image, which multiplies the real and the imaginary parts of the spectrum respectively, or a 2 channel complex image, which multiplies the spectrum by a complex number. Its size must be exactly the same as the frequency image.

Parameters
[in]freqImg The input image in the frequency domain
[in]filterImgThe input filter image, it should be a real image or a complex image with the same size as freqImg
[out]result Return the filtered frequency image, the size is the same as the input
Since
2.24.0

◆ GenGabor()

void GenGabor ( double  angle,
double  frequency,
double  bandwidth,
double  orientation,
ILImage *  filterImg 
)

Generates a Gabor filter image, which is a bandpass filter with both a frequency selectivity and a direction selectivity, so it's useful to enhance the similar textures with both a similar scale and a similar direction.

The generated image is a 2 channel image, channel 0 is the Gabor response and channel 1 is the corresponding Hilbert response, therefore it's applied by ApplyGabor() rather than Apply().

Parameters
[in]angleThe angular selectivity, in range 1 ~ 500, a larger value allows a narrower range of directions
[in]frequencyThe relative center frequency, in range 0 ~ 0.7
[in]bandwidthThe relative radial bandwidth factor, in range 0.05 ~ 100, a larger value allows a narrower range of scales
[in]orientationThe main direction of the filter, in degree, in range 0 ~ 180
[out]filterImg Return the 2 channel filter image, both channels are real valued
Since
2.24.0
See also
SetTemplate(), ApplyGabor()

Generates a homomorphic filter image, which suppresses the slowly changed illumination and enhances the details in the same time.

Parameters
[in]gammaLowThe gain of the low frequencies, usually smaller than 1, a smaller value suppresses the uneven illumination more strongly
[in]gammaHighThe gain of the high frequencies, usually larger than 1 and larger than gammaLow , a larger value enhances the details more strongly while it may also amplify the noise
[in]cutFrequencyThe relative transition frequency between the low and the high frequencies, 0 ~ 1
[in]sharpThe sharpness of the transition, a larger value distinguishes the background and the details more clearly

Specifies the spectrum template which the generated filter images are used for. It sets Width , Height and DCTerm at once, so that a generated filter always matches the spectrum produced by LFreqTransform.

Note: dct must be the same as the LFreqTransform::DCTerm which produced the frequency image.

Parameters
[in]wThe width of the spectrum, in pixel
[in]hThe height of the spectrum, in pixel
[in]dctThe layout of the DC component in the spectrum, see LPVDCTermMode

◆ DCTerm

LPVDCTermMode DCTerm
getset

The layout of the DC component used by the generated filter images, see LPVDCTermMode. The default value is LPVFreqDCCenter.

Note: it must be the same as LFreqTransform::DCTerm which is used to produce the frequency image, otherwise the filter is misaligned with the spectrum and the filtered result is wrong.
