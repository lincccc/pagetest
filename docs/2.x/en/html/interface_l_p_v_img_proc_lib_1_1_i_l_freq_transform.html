Detailed Description

This interface provide functionalities of image frequency transform such as FFT, and the analysis of the frequency domain image, such as magnitude, phase and phase correlation.

To use this interface, you should create a LFreqTransform object.

The transform always yields a full-spectrum complex image, the layout of the spectrum is controlled by DCTerm. A complex image has 2 channels, channel 0 is the real part and channel 1 is the imaginary part.

The properties are the setup used by the forward transforms, they don't affect any method output guarantee.

Since
2.20.0

void FFT ( ILImage *  img,
ILImage *  freqImg 
)

Calculates the Fourier transform of the input image, transforms it into the frequency domain, using fast Fourier transform (FFT) algorithm. The input image is converted to grayscale if it's a color image, and to 32-bit float before the transform. The WindowFunction is applied to the input image before the transform to reduce the spectral leakage. To restore the image, call FFTInv() with the same DCTerm .

Parameters
[in]img The input image
[out]freqImg Return Fourier-transformed image, the size is the same as the input image
Since
2.20.0

void Magnitude ( ILImage *  freqImg,

BOOL  doLn

Calculates magnitude of the frequency domain image, the modulus of the frequencies, as: \( \sqrt{r^2 + i^2} \) .
If doLn is set to True, then additionally, the natural logarithm is applied to the result, as: \( \ln{\sqrt{r^2 + i^2}} \) .

Parameters
[in]freqImg The input image in the frequency domain
[out]magImg Return the magnitude image
[in]doLnWhether the natural logarithm is applied, default to False.

◆ PhaseCorrelation()

void PhaseCorrelation ( ILImage *  freqImg1,
ILImage *  freqImg2,
ILImage *  result 
)

Calculates the normalized cross-power spectrum of the 2 input frequency images, used for the phase correlation. It's computed as: \( \frac{conj(F_1) \cdot F_2}{|conj(F_1) \cdot F_2|} \) .
The result is still a frequency domain image, to locate the peak (aka. the shift between the 2 input images), transform it back into the spatial domain with FFTInv().

Parameters
[in]freqImg1 The first input image in the frequency domain
[in]freqImg2 The second input image in the frequency domain
[out]result Return the normalized cross-power spectrum, the size is the same as the inputs
Since
2.24.0

◆ ShapeFactor

double ShapeFactor
getset

The shape factor which affects the Kaiser window function, it's only used when WindowFunction is LPVWindowKaiser. A larger value suppresses the leakage more strongly, while a smaller value makes the frequency peak sharper. The default value is 0.5, the valid range is 0 ~ 10, set out of the range throws an exception.

Since
2.24.0
See also
WindowFunction

◆ WindowFunction

LPVWindowFunction WindowFunction

The window function applied to the input image before the forward transform, used to reduce the spectral leakage. It only affects FFT(), FFTByRow() and FFTByCol(), the inverse transforms never apply a window. The default value is LPVWindowNone, see also LPVWindowFunction.
