◆ LPVConductivity

enum LPVConductivity

This enumeration represents the type of the conductivity coefficient used in AKAZE feature.

For all the equations below, \( dL \) is the first order image derivative, \( k \) is the contrast factor.

Enumerator
LPVConductPMG1 

Perona & Malik G1: \( \exp{(-dL^2 / k^2)} \)

LPVConductPMG2 

Perona & Malik G2: \( 1 / (1 + dL^2 / k^2) \)

LPVConductWeickert 

Weickert: \( -3.315 / (dL^2 / k^2)^4 \)

LPVConductCharbonnier 

Charbonnier: \( 1 / \sqrt{(1 + dL^2 / k^2)} \)

◆ LPVFeatureType

enum LPVFeatureType

This enumeration represents the type of feature extracted from the image.

Enumerator
LPVFeatureReserved 

Not-initialized feature.

LPVFeatureORB 

ORB(Oriented FAST and Rotated BRIEF) feature. Combines the FAST keypoint detector with the rotation-aware BRIEF descriptor, produces binary features that are fast to extract and match. Commonly used for real-time object detection, image matching and visual odometry.

LPVFeatureHOG 

HOG(Histogram of Oriented Gradients) feature. Builds the histogram of local gradient directions in cells, which is robust to illumination change. Commonly used for pedestrian detection and general object detection.

LPVFeatureAKAZE 

AKAZE(Accelerated-KAZE) feature. Detects keypoints in the nonlinear scale space built with fast explicit diffusion, and is rotation invariant. Commonly used for feature matching, image stitching and 3D reconstruction.

LPVFeaturePixelByPixel 

Pixel-by-pixel feature. Every pixel of the uniformed sample image is taken as one dimension of the feature vector, so the spatial gray information of the sample is fully kept. Commonly used for defect inspection and small-sample classification that rely on texture or gray details.

LPVFeatureSIFT 

SIFT(Scale-Invariant Feature Transform) feature. Detects keypoints across the scale space and describes them with local gradient statistics, invariant to scale, rotation and illumination change. Commonly used for image matching, stitching, recognition and 3D reconstruction.

LPVFeatureHaar 

Haarlike feature. Describes the local gray difference with rectangular Haar-like templates of various scales, which can be computed fast with the integral image. Commonly used for face detection and boosting-based object detection.

LPVFeatureShape 

Shape feature. Describes the sample shape with the shape context and the distribution of keypoints, capturing both local and global geometry. Commonly used for shape matching and classification of irregular or hollow parts.

LPVFeatureNewBrief 

NewBrief feature. A binary descriptor of local image patches based on intensity comparisons, fast to compute and to match with the Hamming distance. Commonly used for feature matching and image retrieval.

LPVFeatureGGCM 

GGCM(Gray-Gradient Co-occurrence Matrix) feature. Statistics of the co-occurrence of gray levels and gradient values, which reflects the texture property of the image. Commonly used for texture analysis and surface defect classification.

LPVFeatureIntegralHist 

IntegralHist(Integral Histogram) feature. Computes the histogram of any rectangular region in constant time from an integral histogram. Commonly used for region-based texture and color statistics in object detection.

LPVFeatureMLP 

MLP feature. The feature vector produced by an ANN(MLP) network, which maps the raw sample to a compact learned representation. Commonly used for classification with learned features.

◆ LPVKNNDistance

enum LPVKNNDistance

This enumeration represents the distance calculation method used in KNN model for measuring the similarity between samples.

For all the equations below, x and y is the two feature vectors of the two samples to compare, i is for the ith value.

Enumerator
LPVKNNDistanceEuclidean 

Euclidean(L2): \( \sum{(x_i - y_i)^2} \)

LPVKNNDistanceManhattan 

Manhattan(L1): \( \sum{|x_i - y_i|} \)

LPVKNNDistanceMax 

Maximum: \( \max{|x_i - y_i|} \) Only works with BruteForce or K-Means or Hierarchical matching

LPVKNNDistanceHistIntersection 

Histogram Intersection: \( \sum{\min{(x_i, y_i)}} \)

LPVKNNDistanceHellinger 

Hellinger: \( \sum{(\sqrt{x_i} - \sqrt{y_i})^2} \)

LPVKNNDistanceChiSquare 

Chi-Square: \( \sum{((x_i - y_i)^2/(x_i + y_i))} \text{ for } x_i + y_i > 0 \)

enum LPVKNNMatchAlgo

This enumeration represents the algorithm for the nearest searching used in KNN model.

Enumerator
LPVKNNMatchBruteForce 

The naive Brute-Force algorithm, aka. searching one-by-one, used for small dataset.

LPVKNNMatchKDTree 

The samples are organized and searched in several KD-Trees.

LPVKNNMatchKmeans 

The samples are organized via K-Means algorithm.

LPVKNNMatchComposite 

Composite with KD-Tree and K-Means

LPVKNNMatchHierarchical 

The samples are organized via hierarchical clustering

LPVKNNMatchAuto 

The samples are organized via auto-tuned indexing

◆ LPVPixelValueType

enum LPVPixelValueType

This enumeration represents the type of the pixel value used in the PixelByPixel feature.

Enumerator
LPVPixelValueGray 

The gray value in 0 ~ 1

LPVPixelValueGrayNorm 

The gray value normalized with maximum scaling to 0 ~ 1

LPVPixelValueBinary 

The binary value after auto-thresholding, bigger pixels report 1, otherwise report 0.
If a region is available, the region's mask is used as the source; if the region is using a soft mask, a floating value between 0 ~ 1 is reported.

LPVPixelValueFraction 

The fraction of foreground pixels after auto-thresholding

This enumeration represents the type of the kernel used in the SVM model.

For all the equations below, x and y is the two feature vectors of the two samples to compare, g, c and n are numeric parameters.

Enumerator
LPVSVMKernelLinear 

Linear: \( x^Ty \)

LPVSVMKernelPolynomial 

Polynomial: \( (g \cdot x^Ty + c)^n \)

LPVSVMKernelRBF 

RBF: \( \exp{(-g \cdot |x - y|^2)} \)

LPVSVMKernelSigmoid 

Sigmoid: \( \tanh{(g \cdot x^Ty + c)} \)
