Detailed Description

This interface provide functionalities of barcode detection and quality verification.

Most popular 1D(linear) and 2D barcode symbologies are supported, see LPVBarcodeType for detailed list. The verification follows ISO-15416 standard for 1D codes, and ISO-15415 for 2D codes.

To use this interface, you should create a LBarcodeDetector object.

Example Code

C++
ILBarcodeDetectorPtr barcodeDetector = LBarcodeDetector::Create();
barcodeDetector->Type = LPVBarcodeType::LPVBarcodeAll1D; // detect all types of 1D barcode
barcodeDetector->VerifyQuality = VARIANT_TRUE; // do quality verification during detection
barcodeDetector->MaxCount = 3;
LPVErrorCode err = barcodeDetector->Detect(img, roi, &codeResults);
if (err != LPVErrorCode::LPVNoError) return;

◆ SymbolSize

int SymbolSize
getset

The expected symbol size, in modules per side of the symbol.
By default, it's 0, meaning the symbol size is not restricted.
A non-zero value requires the symbol to be a square of exactly that size, and also sets SymbolSizeMin and SymbolSizeMax to the same value. The get reports the size only while the accepted sizes form that single square, otherwise it reports 0.
Note this is the number of modules in the symbol, not the size of a single module, the latter is ModuleSize.

A non-zero value must be a symbol size allowed by the symbologies being detected (see Type), otherwise it is rejected. The actual symbol sizes of each symbology are:

SymbologyEffective sizes (modules per side)
Data Matrix (ECC 200)square 10×10 ... 144×144; rectangular 8×18 ... 16×48
Micro QR Code11×11, 13×13, 15×15, 17×17
QR Code21×21 ... 177×177 (version 1~40, step 4)
Aztec Code15×15 ... 151×151 (compact 15~27, full range 19~151)
PDF4173~90 rows, 1~30 data columns (not module sides)
MaxiCodefixed 30×33 hexagonal grid, no size choice

Rectangular symbol sizes, e.g. \( 8 \times 18 \) , cannot be expressed by this single value and are searched only while it is 0; use SymbolSizeMin and SymbolSizeMax to restrict them by a size range.

Since
2.23.0

◆ WideSearch

BOOL WideSearch
getset

Whether to enable the wide-area coarse search to locate barcodes before decoding.
By default, it's True, meaning the whole detection region is searched for candidate code areas before the precise decoding, which is suitable for locating a barcode in a large region; False skips this coarse search and decodes directly, which is faster and usually sufficient when the region of interest is small.

Enabling it may significantly increase the runtime.
Currently, this setting only applies to Data Matrix codes.
